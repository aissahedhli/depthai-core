Description:

Installe le SDK Python DepthAI pour les caméras OAK de Luxonis, ainsi que les règles udev nécessaires à leur détection.

Fonctionnalités:

Installation du SDK Python DepthAI via pip.

Ajout des règles udev pour la reconnaissance des caméras OAK.

Installation des dépendances Python requises : numpy, opencv, pyserial, libusb1.

Installation :

    Le paquet installe les règles udev dans /etc/udev/rules.d/.

    Le SDK DepthAI est installé via pip : pip3 install depthai.

Dépendances :

    python3

    python3-pip

    python3-numpy

    python3-opencv

    python3-pyserial

    libusb1
